# PAL MVP Demo

A local, single-file prototype. Open `index.html` in a modern browser—no server or account is required.

## Demo path

1. Choose **Start sample profile**.
2. Review the PAL design and choose a room.
3. Switch between Room View and Explorer Mode.
4. In Explorer Mode, use WASD/directional keys and E, or click room objects directly.

All panels and modes can be closed with their close control or Escape.
